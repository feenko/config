# @fnko/config

## Philosophy

Rules in [`core`](./src/oxlint/core.ts) are already strict, which is done on purpose to enforce consistency where it makes sense. [`strict`](./src/oxlint/strict.ts) uses even more opinionated rules that might not fit all codebases.

Rule selection is subjective, so if you disagree with any choice, feel free to [raise an issue](https://github.com/feenko/config/issues/new).
